# Roadmap

This document outlines the strategic vision and upcoming features for Hamara Editor.

## Version 2 (Upcoming)
- Language Server Protocol (LSP) integration for autocompletion.
- Multi-file workspaces.
- Custom environment variable injection per execution.
- Support for compiled languages (Java, C++).

## Version 3
- Real-time multiplayer collaboration (CRDTs/Yjs).
- Project sharing and public URLs.
- Embedded databases for users (e.g., ephemeral SQLite per session).

## Future Initiatives

### AI Integration
- Introduce an AI copilot that lives directly in the editor, aware of the user's execution context.
- AI-driven debugging for failed execution traces.

### Collaboration & Education
- Voice and video chat integrated into workspaces.
- "Classroom" mode for educators to assign code templates and auto-grade execution outputs.
