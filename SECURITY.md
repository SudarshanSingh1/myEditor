# Security Policy

## Supported Versions

We currently provide security updates for the following versions of Hamara Editor:

| Version | Supported |
| ------- | --------- |
| 1.x.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **DO NOT** open a public issue.

Instead, please send an email to the maintainers at [SECURITY_EMAIL].
We will respond within 48 hours to acknowledge the report and outline the next steps.

### Scope

We are particularly interested in vulnerabilities related to:
- Container escapes in the Execution Engine.
- Privilege escalation.
- Cross-Site Scripting (XSS) in the editor UI.
- Leaked credentials or JWT mishandling.
